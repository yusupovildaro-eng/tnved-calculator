### Аутентификация и пользователи
- HMAC-SHA256 подписанные сессионные куки
- pbkdf2_hmac хеширование паролей
- Хранилище пользователей: Upstash Redis KV
- Авто-миграция старого формата `{user: "pbkdf2:..."}` → новый `{user: {...}}`
- Пользователи: Ildar Yusupov (∞), Konstantin (∞), Dmitriy (10 токенов)

### Структура данных пользователя (KV)
```json
{
  "username": {
    "password": "pbkdf2:salt:key",
    "tokens": 5,
    "created_at": "2026-06-28",
    "paid_at": "2026-06-03",
    "is_new": false,
    "first_name": "Иван",
    "last_name": "Иванов",
    "inn": "123456789",
    "phone": "+998901234567",
    "org": "ООО «Компания»",
    "reg_ip": "1.2.3.4"
  }
}
```

### Система токенов/запросов
- `tokens=null` → безлимит (∞)
- `tokens>0` → ограничено
- `tokens=0` → заблокирован
- Списание: только при нажатии кнопки **РАССЧИТАТЬ**
- Без списания: повторный расчёт с теми же данными, выбор кода из поиска
- Срок подписки: `paid_at + 30 дней`
- Бейдж с остатком токенов в шапке, обновляется без перезагрузки
- Toast-уведомление при исчерпании токенов

### Страница регистрации (`/register`)
- Поля: Имя, Фамилия, ИНН, Организация, Телефон, Логин, Пароль (×2)
- Модальное окно «Условия использования» (полноэкранное)
- После регистрации: 5 бесплатных запросов, `is_new=true`

### Защита от злоупотреблений
- Уникальность ИНН при регистрации
- Уникальность телефона при регистрации
- Максимум 3 аккаунта с одного IP

### Приветственное окно
- Показывается один раз при первом входе
- Анимированный модал: поздравление + инфо о 5 подаренных токенах
- Флаг `is_new` сбрасывается в KV после показа

### Админ-панель (`/admin`)
